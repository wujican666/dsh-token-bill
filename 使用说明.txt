dsh-token-bill —— DSH Token 总账
=================================

这是什么
--------
把你电脑上 DeepSeek Harness（DSH）的会话日志算成一张网页账单：
白嫖（学校 API / 免费额度）了多少 token、自费了多少、每天用了多少。
全部在你本机算，不联网、不上传、不花一分钱。

怎么用（三步）
--------------
1. 先把整个压缩包解压出来（别在压缩包里直接双击）
2. 进 dsh-token-bill 文件夹，双击 dsh-token-bill.exe
3. 它会在同目录生成「token-账单.html」，并自动用浏览器打开；窗口 4 秒后自己关

前提
----
这台电脑上装过 DSH 并且用它聊过天（要有 C:\Users\你的用户名\.dsh\sessions 里的日志）。
没有日志的话，页面会提示你，不会报错。

想更准一点
----------
1. 把 token-bill.config.example.json 复制成 token-bill.config.json，放在 exe 旁边
2. 打开你 API 平台的账单页，把真实实付金额填进 "paid_actual_cny"，日期填 "paid_actual_date"
3. 再双击 exe，「自费」那一栏就显示真钱，白嫖率也跟着变准

某个平台被算错了 / 页面上写着「待确认」？
----------------------------------------
认不出来的平台不会被算成自费，只会单独列在页面上（免得给你算错账）。
页面上还有一张「每个 provider 是怎么判定的」表，写清每个平台是按哪条规则归类的。
要修正：把名字加进 token-bill.config.json 的 "free_providers"（学校 / 公司 / 自建的免费额度）
或 "paid_providers"（真花钱买的平台），再双击一次 exe 就行。
懒得一个个挑：在文件夹地址栏输入 cmd 回车，然后运行
    dsh-token-bill.exe --unknown free
（认不出来的全按免费额度算；想按自费就用 --unknown paid）

页面打不开 / 找不到日志？
-------------------------
在文件夹地址栏输入 cmd 回车，运行 dsh-token-bill.exe --doctor
它会告你：日志在哪个目录、找到几个、是压缩还是纯文本、每个平台怎么判定的。

想让作者把你们学校 / 公司的写法加进内置规则？
--------------------------------------------
同一个命令行窗口里运行 dsh-token-bill.exe --rules
它只打印平台名和判定结果（没有金额、没有 token 数），把清单贴到仓库 issue 即可。

双击 exe 没反应 / 提示「应用控制策略已阻止此文件」？
----------------------------------------------------
这是 Windows 自己的安全策略（智能应用控制 / 学校或公司统一下发的 WDAC 策略）挡住了没签名的 exe，
不是程序坏了，也不是病毒。三条出路，任选一条：
1. 懒得折腾：用源码方式跑 —— 看下面的「用源码跑（不需要 exe）」。
2. 自己的电脑：设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 →
   智能应用控制 → 关闭。（注意：智能应用控制一旦关闭，除非重装系统否则不能再打开）
3. 学校 / 公司发的电脑：策略是 IT 统一下发的，改不了，直接用源码方式跑。

用源码跑（不需要 exe）
----------------------
1. 装一次 Python：https://www.python.org/downloads/ ，安装时勾上 "Add python.exe to PATH"
2. 双击本文件夹里的 run-source.cmd（它会在本目录生成同一张网页账单）
   Python 3.12 / 3.13 需要先跑一次：py -m pip install zstandard
